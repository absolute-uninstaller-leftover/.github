# Absolute Uninstaller - Standard Remove or a Dead-Entry Force

## At a Glance

Glary's Absolute Uninstaller is a desktop program list for Windows. The ordinary command is the one stored when the software was installed. The force command is for the case where that command points at nothing and Settings still shows the name. Leftovers are searched afterward so a folder under Program Files does not keep the size you thought you freed.

- Sortable list of desktop installations  
- Normal uninstall when the vendor command exists  
- Force path when the command is missing  
- Leftover review with names you can reject  
- Not a Windows Store removal tool and not a driver-store cleaner  

## When Force Is Honest

Force is honest when you click uninstall, the system says the file is missing, and the product is already useless. Force is not honest when the wizard opened and asked a question you did not want to answer. Cancelling a wizard and then forcing the entry leaves the product's files and services in whatever state the wizard had reached. Finish the wizard or leave the entry until you can.

Driver utilities, VPNs, and virtual-drive tools are the force cases that need a second tool afterward. The installer entry can vanish while the filter driver is still set to start. Plan on a services list or Device Manager after any force removal of that kind. Absolute Uninstaller will not pretend it unloaded a kernel driver.

## Leftover Review

| Path you are offered | Verdict |
|---|---|
| Product directory in Program Files | Remove if you looked inside |
| Vendor key that names only that product | Remove |
| A runtime used by other software | Keep |
| A folder in Documents or Desktop | Keep |
| Startup item pointing at a deleted exe | Remove |

## Steps

1. Close the application and note whether you expect a normal uninstall.  
2. Try the standard removal first.  
3. If the uninstall file is missing, use force and write that down.  
4. Decline leftovers that are shared or personal files.  
5. Reboot if the software installed a driver, shell extension, or browser plugin.  
6. Check the tray and startup before you call the visit done.

## Who It Fits

A PC with one broken entry and several ordinary programs you are willing to remove properly. A poor fit for bulk imaging, where a selection list and a log matter more than a force button. A poor fit for malware with no installer entry. Nothing in this list means nothing for this tool to remove.

## Requirements

| Item | Expectation |
|---|---|
| OS | Windows versions the Glary build supports |
| Rights | Administrator for machine-wide products |
| Disk | Freed after files actually leave, not when the list updates |
| Network | Only if the vendor uninstaller downloads a helper |
| Record | Note force versus normal in the ticket |

## Fixes

Standard uninstall cannot find its file. Move to force, then leftovers, then a manual check of services.  
Force finished and the shortcut remains. Delete that shortcut; it is not proof the force failed.  
A second program asks for a missing component. Restore the shared runtime you accepted as a leftover.  
The entry is a Windows update or a security suite. Do not force it. Use the vendor's own removal or leave it.  
The list never shows a portable app. It was never installed. Delete or keep its folder in Explorer with ordinary care.

## Aftercare

One broken entry is a reason to open this tool. Ten force removals in a row are a reason to stop and look at how the PC was built. An image full of dead installer entries will be cleaner if you fix the image than if you force each machine. Use the normal path whenever it exists so the vendor's custom steps still run.

If you are unsure whether a leftover folder holds data, rename it instead of deleting it, reboot, and see what complains. A renamed folder is a reversible test. A deleted documents folder is not.
